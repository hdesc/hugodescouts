d'installation

Ollama fait tourner l'IA sur ton Mac - gratuit, prive, sans abonnement.

1
Installer Ollama
Telecharge sur ollama.com la version Mac (.dmg) et installe-la.
2
Telecharger un modele
ollama run mistral
8 Go - mistral · 16 Go - llama3 · 32 Go - qwen2.5
3
Lancer avec les bons droits
Quitte l'icone dans la barre des menus, puis dans le Terminal :
OLLAMA_ORIGINS="*" ollama serve
Laisse ce Terminal ouvert et ouvre ce fichier dans Chrome.
